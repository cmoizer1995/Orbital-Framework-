# CM Link Bio Widget

## Overview

CM Link Bio Widget is a standalone Elementor widget split from the CM Editorial Widgets master plugin.

It is designed to create a profile and link page directly inside WordPress, without relying on external link-in-bio services.

## Included Files

```text
class-cm-link-bio-widget.php
cm-link-bio-widget.css
README.md
```

## Features

- Elementor widget support
- Link button system
- Profile/bio support depending on settings
- Social link support
- Brand-style colours
- Manual colour support
- Icon and logo support
- Responsive mobile-first layout

## Recommended Use

Use this widget for:

- Link in bio pages
- Creator profile pages
- Social link landing pages
- Portfolio quick-link pages
- Business contact/link hubs

## Requirements

- WordPress
- Elementor
- PHP 8.0 or newer recommended

## Installation Notes

This split package contains the widget files separated from the master plugin.

For production use, package it with a plugin bootstrap file that registers the Elementor widget and enqueues the CSS file.
