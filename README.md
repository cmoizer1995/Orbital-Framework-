# CM Featured News Grid Widget

## Overview

CM Featured News Grid Widget is a standalone Elementor widget split from the CM Editorial Widgets master plugin.

It is designed to display featured content in an editorial grid layout, with a main featured story and supporting content cards.

## Included Files

```text
class-cm-featured-news-grid-widget.php
cm-featured-news-grid.css
README.md
```

## Features

- Elementor widget support
- Featured lead content area
- Supporting grid layout
- Responsive design
- Image display support
- Text/title/excerpt display support
- Suitable for blogs, news, and portfolio layouts

## Recommended Use

Use this widget for:

- Blog landing pages
- News grids
- Featured posts
- Magazine-style layouts
- Portfolio feature sections

## Requirements

- WordPress
- Elementor
- PHP 8.0 or newer recommended

## Installation Notes

This split package contains the widget files separated from the master plugin.

For production use, package it with a plugin bootstrap file that registers the Elementor widget and enqueues the CSS file.
