# CM Laboratory Hero Widget

## Overview

CM Laboratory Hero Widget is a standalone Elementor widget split from the CM Editorial Widgets master plugin.

It is designed for creating large hero sections for homepages, landing pages, project pages, service pages, and featured content areas.

## Included Files

```text
class-cm-laboratory-hero-widget.php
cm-laboratory-hero-widget.css
README.md
```

## Features

- Elementor widget support
- Responsive hero layout
- Large editorial-style hero section
- Custom text areas
- Button/link support
- Image/background support depending on widget setup
- Works as part of the Orbital Framework system

## Recommended Use

Use this widget for:

- Website home hero sections
- Service page headers
- Portfolio project headers
- Featured article banners
- Landing page introductions

## Requirements

- WordPress
- Elementor
- PHP 8.0 or newer recommended

## Installation Notes

This split package contains the widget files separated from the master plugin.

For production use, package it with a plugin bootstrap file that registers the Elementor widget and enqueues the CSS file.
