# CM Timeline Widget

## Overview

CM Timeline Widget is a standalone Elementor widget split from the CM Editorial Widgets master plugin.

It is designed to create responsive timelines with desktop left/right entries and stacked mobile entries.

## Included Files

```text
class-cm-timeline-widget.php
cm-timeline-widget.css
README.md
```

## Features

- Elementor widget support
- Desktop left/right timeline layout
- Mobile stacked timeline layout
- Timeline entry repeater
- Month/year fields
- Title and description fields
- Timeline line and dot styling
- Per-item colour support depending on widget version
- Button/link support depending on widget version

## Recommended Use

Use this widget for:

- Project timelines
- Company history
- Roadmaps
- CV/work history
- Milestone pages
- Event timelines

## Requirements

- WordPress
- Elementor
- PHP 8.0 or newer recommended

## Installation Notes

This split package contains the widget files separated from the master plugin.

For production use, package it with a plugin bootstrap file that registers the Elementor widget and enqueues the CSS file.
